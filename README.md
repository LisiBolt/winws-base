# winws-base
Категорийная база доменов для WinwsTester. Только данные, без кода.

Формат: ключ = домен или суффикс с точкой (".rbxcdn.io");
значение = {"service","category","color","manual":bool,"auto":bool}
- manual:true — ручная правка пользователя, синхронизация НЕ перезаписывает
- auto:true   — автодетект, синхронизация может обновить
